In my Capstone Project 1, I created a simple multi-page personal website using only HTML. It included pages like Home, Education, Schedule, Contact, and Questionnaire. At that stage, the website worked correctly, but it had no styling or layout structure — everything looked plain and basic.

In Capstone Project 2, I improved the same website by adding CSS and Bootstrap to make it more attractive, organized, and responsive. I created a new external stylesheet called style.css and connected it to all pages. Using CSS, I gave the whole site a dark purple theme, changed the fonts using Google Fonts, and centered the body to 90% of the screen width. I also styled the horizontal rules, lists, tables, and forms to make them look cleaner and more professional.

I added a sticky navigation bar that stays on top of the page while scrolling and shows hover effects for each link. The active page link is styled differently, which helps users know which page they are on. I also made my profile picture circular and added a small hover effect to make it grow when the mouse is over it.

For layout practice, I used Flexbox, Grid, and Position techniques to organize page content in different ways. I also created a new Gallery page with 3–4 images arranged in a responsive grid — three images per row on desktop and one per row on mobile screens.

Finally, I added Bootstrap only to the Questionnaire page. With Bootstrap, I used the grid system, buttons, form components, and spacing utilities to make the questionnaire easier to read and use. The Bootstrap design matches the rest of my website because I customized the colors to fit my dark purple theme.

Overall, this project helped me understand how to combine HTML with CSS and Bootstrap to create a well-styled, responsive, and user-friendly personal website. I learned how to structure a webpage, apply consistent styles, and use frameworks to save time while designing.
